浏览器里跑真原生代码

每个工具的内核都是编译成 WebAssembly 的原生程序 —— 不上传、不联网、装完就能离线用。可以整体下载，也可以只要那个 .wasm 模块。

12在线工具
~25KB轻量内核均值
0数据上传
PWA可安装为应用
怎么离线用？下载 HTML 后，把它和对应的 .wasm 放在同一个目录下， 双击 HTML 即可离线运行（部分浏览器需用本地服务器，因为 file:// 下不能 fetch wasm）。
只要内核？点「WASM」下载原生模块，自己写宿主页面 fetch → WebAssembly.instantiate 就能调用。
标注 CDN 的工具内核体积较大（10–90MB），由官方 CDN 加载，不提供单文件下载。
