体验 Candle 在线演示 ↗ GitHub 源码 ↗

这是 Hugging Face 上的官方关联演示，页面、量化模型和音频样例由 Hugging Face 提供；Candle 在浏览器本地执行 Rust/WASM 推理。与上方 lain42 OSS 工作台分开。

🎙️ 音频转文字

选择常见音频文件，Whisper Tiny 会在本机识别语音。最多 90 秒，支持中文和多种语言。

🔎 按意思搜索笔记

每行一条资料。E5 会区分“词相同”和“意思相近”，适合查找自己的摘录、灵感或会议记录。

🏷️ 用自己的标签分类

定义标签，不需要训练。适合把反馈分成“退款、故障、功能建议”等类别，结果只保留在当前页面。
