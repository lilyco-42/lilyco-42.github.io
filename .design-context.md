# Lain42 site design context

## Product and audience

This repository is the public Lain42 / 云枢智创 project and browser-tool site. Visitors browse projects, read getting-started guides, and use self-contained WASM tools from desktop and mobile browsers. The audience includes developers and non-specialist makers using Chinese-first interfaces.

## Redesign direction

The user explicitly requests one consistent ChatGPT and Apple-inspired visual style across every HTML page. Use a quiet light workspace: warm-neutral canvas, white surfaces, dark readable text, restrained green brand accent, clear borders, system fonts, and large touch targets. Avoid gradients as decoration, glass effects, heavy shadows, and external font or style dependencies.

## Scope and constraints

- Apply the shared design system to every checked-in HTML page, including `/`, `/guide.html`, `/design.html`, `/rembg/`, `/pet/`, `/tool/`, `/wasm-demo/`, and all `/lyco/*` pages.
- Keep each tool's information architecture, interactions, URLs, calculations, WASM loading, and canvas/editor surfaces intact. Shared styling must not replace tool-specific behavior.
- Independent services hosted outside this repository (for example the API gateway, compute market, and proxy panel) are not owned by these files and cannot be changed from this checkout.
- All assets remain self-hosted; do not add CDN or web-font dependencies.
- Support keyboard focus, reduced motion, contrast, narrow phone screens, and 44px controls.

## Design audit

Before this pass the 22 HTML pages had separate inline styles, multiple incompatible color systems, and inconsistent control sizes. Most tools had useful, purpose-built layouts worth preserving, so the redesign shares tokens and common control/surface styling instead of rebuilding each tool's behavior or forcing one page layout on all tools. The desktop pet's animated scene and code/editor canvases remain specialized content surfaces.

## Verification

Use GitHub Actions for static page coverage checks and existing browser/tool tests. Do not run local builds or tests for this project; the user requested GitHub Actions as the verification path.
