01视觉主题

像 ChatGPT / Kimi 的深色工作台：左侧固定导航，右侧单列内容。工具感、可信、低噪音。 本页会跟随你的系统主题 —— 切到浅色模式可看到浅色版本（prefers-color-scheme）。

气质

  • 密度中等：卡片间距 .9rem，正文行高 1.65
  • 动效极少：只有侧栏抽屉有 transform .2s
  • 无插画、无渐变滥用、无糖果色大圆角

三条哲学（冲突时按序）

  • 内容 > 容器 —— 卡片只分组，不装饰
  • --acc 是唯一强调色 —— 只给可点击元素与 .tag 标签
  • 一个视图一件事 —— 不堆叠信息

06层次：不用阴影

层次靠背景色阶（3 层）+ 1px 描边 表达。禁止 box-shadow / 玻璃模糊 —— 深色下阴影几乎不可见，只增加噪音。

层级表面表达
0 导航--sidebar最暗，靠右描边与主区分离
1 画布--main基础底
2 内容--card + --edge卡片
3 反馈--card2hover 加深

07Do / Don't

Do

  • 颜色一律走 token：var(--acc)
  • 外部链接加 target="_blank" rel="noopener"
  • 站内相对链接相对文件所在目录写
  • 图片带 width/height 与 alt
  • 空态 / 错误态写中文人话
  • 新 logo 沿用「圆角矩形 + 两字母缩写」
  • 点击目标补 role="button" + tabindex="0" + Enter/Space
  • <head> 带 color-scheme / description / favicon

Don't

  • 不要把 --acc 用在既非交互、也非标签的文字上
  • 不要引入 webfont / CDN（页面零外部请求）
  • 不要用 box-shadow 做层次
  • 不要给卡片加大圆角（>14px）或彩色边框
  • 不要在页面里写死会过期的数字
  • 不要把 div 当按钮用而不给键盘支持
  • 不要写死只在深色下成立的透明色（走 token）

08响应式

唯一断点 860px。≤860px 时侧栏变抽屉（translateX(-100%)），汉堡按钮出现，触摸目标 ≥44px。

宽度行为
> 860px侧栏常驻左侧 264px；内容区居中 860px
≤ 860px侧栏固定定位移出屏幕；汉堡按钮出现；主区 padding 收窄至 1.2rem 1.1rem 2rem

同时必须尊重两个偏好：prefers-reduced-motion（取消动效）与 prefers-color-scheme（切换主题）。

键盘焦点必须可见：全局 :focus-visible { outline:2px solid var(--acc) } —— 不要用 outline:none 抹掉。

移动端触摸目标：.nav-item 44px · .side-repo / .side-foot a 40px · .lang 34px。

09给 AI agent 的提示词

在 lilyco-42.github.io 里新增一个页面。严格遵守 DESIGN.md： 用 :root 里的 CSS 变量，不硬编码颜色；卡片用 --card 底 + 1px var(--edge) 描边 + 12~14px 圆角；不加 box-shadow； --acc 只用于可点击元素与 .tag；正文行高 ≥1.5；中文文案；支持 prefers-color-scheme: light 与 prefers-reduced-motion； 移动端（≤860px）触摸目标 ≥44px；页面零外部请求； <head> 带 color-scheme / description / favicon； 非 <a>/<button> 的点击目标补 role="button" + tabindex="0" + Enter/Space。
